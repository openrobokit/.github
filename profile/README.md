# OpenRoboKit

Open-source tools for robot optimization, motion planning, and human-to-robot retargeting.

- **[RoboKit](https://github.com/openrobokit/robokit)**: A high-performance, general-purpose toolkit for versatile robotic tasks.
- **[RetargetingKit](https://github.com/openrobokit/retargetingkit)**: Map live or recorded human motion to robot hands, arms, and humanoids.

[Website & documentation](https://openrobokit.com)
