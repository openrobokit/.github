# OpenRoboKit

Open-source tools for robotics, from agent workflows to optimization, retargeting, and grasping.

- **[RoboSkills](https://github.com/openrobokit/roboskills)**: A low-cost, minimal set of agent workflows and tools for robotics.
- **[RoboKit](https://github.com/openrobokit/robokit)**: A high-performance, general-purpose toolkit for versatile robotic tasks.
- **[RetargetingKit](https://github.com/openrobokit/retargetingkit)**: Map live or recorded human motion to robot hands, arms, and humanoids.
- **[GraspKit](https://github.com/openrobokit/graspkit)**: An end-to-end toolkit for manipulation across robot grippers and dexterous hands.

[Website & documentation](https://openrobokit.com)
